# 时间点进度条

在屏幕顶部显示当前时间点剩余时间占比的 ClassIsland 插件。

## 功能

- 进度条显示在屏幕顶部，始终置顶，最大长度为整个屏幕宽度，长度为「剩余时间占比 × 屏幕宽度」。
- 进度条宽度（粗细）、流逝方向（从左往右 / 从右往左）、颜色均可在设置页面调整。
- 距时间点结束不足配置的秒数时，进度条自动切换为警示颜色。
- 可设置为仅当前台窗口处于全屏或最大化状态时显示进度条。
- 当前不处于任何时间点时，进度条自动隐藏。

## 设置

前往【应用设置】→【时间点进度条】进行配置，设置保存在插件配置目录的 `settings.json` 中。

## 开发与调试

使用 NUKE 目标 `InitPluginDevEnv` 初始化插件开发环境后，可通过
`Properties/launchSettings.json` 以 `-epp <输出目录>` 方式启动 ClassIsland 调试插件。
